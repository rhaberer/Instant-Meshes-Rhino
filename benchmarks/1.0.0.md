# Instant Meshes 1.0.0 benchmark

Median solver times in milliseconds on Apple Silicon, macOS 27.2.1. Both implementations used one worker. Each column summarizes six timed solves across two alternating process pairs, with three warm-up solves per process. Timings exclude file I/O and process launch.
